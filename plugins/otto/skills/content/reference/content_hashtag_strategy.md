# Hashtag Strategy

**Template Type:** Reference doc Otto uses to choose hashtags for short-form video captions.
**The rule:** Hashtags help the algorithm categorize the content. They don't go viral on their own. Treat them like a filing system, not a megaphone.

---

## The Mix

Every hashtag set should hit three categories:

**Broad (~30%):** High-volume tags that put the post in big buckets. Examples: `#realestate`, `#realtor`, `#homebuying`. These have huge reach but huge competition. Don't lean on them alone.

**Niche (~50%):** Mid-volume tags that signal a specific audience. Examples: `#firsttimehomebuyer`, `#luxuryrealestate`, `#sellingyourhome`, `#realestatetips`. This is where most engagement actually comes from.

**Local (~20%):** Geo tags for the agent's market. Examples: `#austinrealestate`, `#southaustin`, `#travisheights`, `#atxrealestate`. This is where qualified-buyer reach happens — people searching by neighborhood.

---

## Count by Platform

| Platform | Hashtag Count |
|---|---|
| Instagram Reels | 10-15 |
| TikTok | 4-7 (inline in caption) |
| YouTube Shorts | 3-5 (in description) |
| Facebook Reels | 3-5 (or none) |
| LinkedIn | 0-3, full words only |

Instagram used to reward 30 hashtags; the current algorithm penalizes that as spammy. 10-15 well-chosen tags outperform 30 random ones.

---

## How Otto Picks Hashtags

For each post, Otto looks at:

1. **The content pillar.** "Buyer education" pulls different tags than "Seller education" or "Market commentary."
2. **The agent's market.** Use the city and neighborhoods from their profile — never invent locations.
3. **The specific topic.** A post about home inspections gets `#homeinspection`. A post about staging gets `#homestaging`.
4. **The audience.** First-time buyer post = `#firsttimehomebuyer`. Luxury listing = `#luxuryrealestate`.

## Banned and Discouraged Tags

**Avoid entirely** (algorithm-flagged or spammy):

- `#followforfollow` `#follow4follow` `#likeforlike` `#l4l` `#f4f`
- `#instagood` `#instadaily` `#picoftheday` (too generic, attract bots)
- `#realtorsofinstagram` (over-saturated, low signal)
- Any banned hashtag list — Instagram updates this periodically. When in doubt, search the tag first; if recent posts are spam, don't use it.

**Use sparingly:**

- `#dreamhome` `#dreamhouse` — cliché unless tied to a specific client story
- `#luxury` `#luxurylife` — only on actual luxury listings
- `#blessed` `#grateful` — don't lean on these; they read as filler

## LinkedIn-Specific Rules

LinkedIn hashtags work differently. The platform uses them for topic categorization in feeds, not viral discovery.

- 0-3 hashtags per post. Three max.
- Full words, capitalized properly. `#RealEstate` not `#realestate`. `#HomeBuying` not `#homebuying`.
- Skip the cute ones (`#RealtorLife`). Use professional tags (`#RealEstate`, `#Housing`, `#HomeBuying`, `#Mortgage`).
- Local LinkedIn tags work but are lower-volume — `#AustinRealEstate` will have a small audience.

---

## When in Doubt

- Default to the agent's market in every set.
- Niche always beats broad. A specific tag with 50K posts will out-convert a generic one with 50M.
- If a hashtag has been used 1B+ times, the post will drown. Use sparingly or skip.
- Search the tag before recommending it. If the top posts look like spam, the tag is polluted.
